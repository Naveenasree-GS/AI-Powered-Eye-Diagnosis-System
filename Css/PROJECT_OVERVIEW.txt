PROJECT OVERVIEW - AI Eye Diagnosis & Doctor Consultation System
================================================================

📋 PROJECT SUMMARY
==================
A modern, professional web application for AI-powered eye diagnosis with real-time 
eye scanning, image analysis, and doctor consultation booking.

🎯 CORE FEATURES
================

1. 👁️ REAL-TIME EYE SCANNER
   - WebGazer.js integration for browser-based eye tracking
   - Live camera feed and gaze position tracking
   - 9-point calibration system
   - Real-time metrics:
     * Status monitoring
     * Gaze coordinates (X, Y)
     * Confidence scoring (0-100%)
   - Eye movement pattern analysis
   - Health issue detection (tremor, instability)

2. 🔬 AI DIAGNOSIS SYSTEM
   - Patient information collection (Name, Age, Gender, Symptoms)
   - Eye image upload and analysis
   - AI-powered image recognition
   - Integration with eye tracking data
   - Combined analysis report generation
   - Health issue detection and severity assessment

3. 👨‍⚕️ DOCTOR CONSULTATION
   - 3 specialist doctors with profiles:
     * Dr. Kumar (Ophthalmologist) - 15+ years
     * Dr. Priya (Eye Specialist) - 12+ years
     * Dr. Singh (Retina Specialist) - 18+ years
   - Appointment scheduling system
   - Date/time selection
   - Doctor selection and booking

🔧 JAVASCRIPT MODULES
======================

demo.js:
- analyzeImage(): Combines eye scan + image analysis
- exportMedicalReport(): Generates medical reports

eye-scanner.js:
- startEyeScanning(): Initialize camera and tracking
- stopEyeScanning(): Stop tracking and cleanup
- calibrateEyes(): 9-point calibration UI
- trackGazePosition(): Real-time gaze tracking
- monitorEyeData(): Display tracking metrics
- analyzeEyePatterns(): Detect anomalies
- detectEyeHealthIssues(): Health assessment
- getEyeScanResults(): Export scan data
- exportEyeScanData(): Download JSON data

✨ USER WORKFLOW
================

1. USER VISITS SITE
   ↓
2. CHOOSES TAB (Scanner, Diagnosis, or Consultation)
   ↓
3. IF SCANNER:
   - Clicks "Start Eye Scan"
   - Allows camera access
   - Sees real-time gaze tracking
   - Can calibrate eyes
   ↓
4. IF DIAGNOSIS:
   - Enters patient info
   - Uploads eye image
   - Clicks "Analyze Image"
   - Views AI analysis + eye tracking data
   ↓
5. IF CONSULTATION:
   - Selects doctor
   - Chooses appointment date/time
   - Confirms booking
   ↓
6. RECEIVES COMPREHENSIVE REPORT
