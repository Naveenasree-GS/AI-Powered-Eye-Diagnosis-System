🐛 TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════

PROBLEM → SOLUTION

Server won't start:
  • Check Java is installed: java -version
  • Verify port 8000 is free: netstat -ano | findstr :8000
  • Kill existing process: taskkill /F /IM java.exe

Browser won't load page:
  • Ensure server is running
  • Try: http://localhost:8000
  • Check firewall settings
  • Try different port

Camera not working:
  • Check browser permissions
  • Ensure camera isn't in use
  • Try different browser
  • Check camera in Device Manager

Eye tracking not accurate:
  • Improve lighting
  • Run calibration
  • Clean camera lens
  • Adjust camera height

Data not saving:
  • Check localStorage is enabled
  • Clear browser cache
  • Check available storage
  • Try private browsing mode

Compilation error:
  • Ensure EyeCareServer.java exists
  • Check file isn't corrupted
  • Try full Java path
  • Check for encoding issues
