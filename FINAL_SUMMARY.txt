─────────────────
Real-Time Eye Tracking Features:

1. START EYE SCAN
   • Requests webcam permission
   • Initializes WebGazer.js
   • Starts real-time tracking
   • Updates gaze position every 100ms
   • Shows status: "Ready" → "Initializing" → "Scanning"

2. CALIBRATION
   • 9-point calibration grid appears
   • Follow the red dots with your eyes
   • System learns your eye pattern
   • Improves tracking accuracy by 50%

3. REAL-TIME METRICS
   ├─ Status: Current tracking state
   ├─ Gaze Position: X, Y coordinates (pixels)
   └─ Confidence: Accuracy percentage (0-100%)

4. STOP SCAN
   • Stops eye tracking
   • Closes camera stream
   • Clears resources

PROBLEM: "Hmmm... can't reach this page"
SOLUTION:
1. Is Java server running? (Check terminal)
2. Try: http://localhost:8000
3. Check if port 8000 is in use:
   netstat -ano | findstr :8000
4. If in use, kill process:
   taskkill /F /IM java.exe

PROBLEM: "Camera not working"
SOLUTION:
1. Check browser permissions
2. Restart browser
3. Try different browser (Chrome/Firefox)
4. Ensure no other app using camera
5. Check camera is not disabled in BIOS

PROBLEM: "Eye tracking not accurate"
SOLUTION:
1. Improve lighting around you
2. Clean camera lens
3. Run calibration again
4. Adjust camera height/angle
5. Ensure good screen contrast

PROBLEM: "Data not saving"
SOLUTION:
1. Check if localStorage is enabled
2. Try clearing browser cache
3. Check browser's storage settings
4. Use private/incognito mode
5. Check available storage space

PROBLEM: Server won't compile
SOLUTION:
1. Ensure Java is installed:
   java -version
2. Check file path has no spaces
3. Verify EyeCareServer.java exists
4. Try with full path:
   "C:\Program Files\Java\jdk\bin\javac.exe" EyeCareServer.java
